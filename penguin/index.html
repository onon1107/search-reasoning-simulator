    인공지능 프로젝트는 문제 정의 → 데이터 수집 → 데이터 전처리 → 알고리즘 선정 → 모델 학습 → 성능 평가의 여섯 단계로 진행됩니다. 이 시뮬레이터는 그 여섯 단계를 순서대로 따라가며, 각 단계의 핵심 코드를 직접 완성해 보도록 만들어졌습니다.

    !상황

    남극 연구소에서 부상당한 펭귄을 발견했지만, 현재 어떤 종인지 확인할 수 없는 상황입니다. 각 종마다 먹이와 치료 방법이 다르기 때문에 종을 분류하는 일은 매우 중요합니다. 급한 대로 한국 기지에 연락했지만 카메라도 작동하지 않는 난처한 상황에 놓여 있습니다.

    어떻게 하면 펭귄의 부리와 날개 등 생김새만으로 펭귄의 종을 분류하는 인공지능 모델을 개발할 수 있을까요?

    ◉ SDGs 14 · 해양 생태계 보전 기계학습 유형 · 분류(Classification)

    ?어떤 정보가 필요할까

    팔머(Palmer) 군도에서 2007~2009년에 수집된 펭귄 344마리의 측정 기록을 사용합니다. 모델은 아래 네 가지 신체 측정값만으로 종을 맞혀야 합니다.

    species펭귄의 종류 — 맞혀야 하는 값(Adelie·Chinstrap·Gentoo)
    island관측한 섬의 이름 (Torgersen·Biscoe·Dream)
    culmen_length_mm부리의 길이 (mm)
    culmen_depth_mm부리의 깊이 (mm)
    flipper_length_mm지느러미 길이 (mm)
    body_mass_g펭귄의 체질량 (g)
    sex펭귄의 성별 (MALE·FEMALE)

    표준화를 하면 k-NN의 성능은 어떻게 달라질까?

    k-NN은 '거리'로 판단하기 때문에 숫자의 크기(단위)에 매우 민감합니다. 체질량은 3000~6000, 부리 깊이는 13~22 범위입니다. 거리를 계산하면 체질량의 차이가 모든 것을 압도해 버립니다. StandardScaler로 모든 속성을 평균 0, 표준편차 1로 맞춰 봅시다.
