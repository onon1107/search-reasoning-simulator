의미망 — 알맞은 그림 고르고 코드로 옮기기

자연어 지식 → 알맞은 의미망 고르기 → 술어 논리 코드 고르기, 두 단계로 연습합니다. 첫 문제는 교과서의 세종대왕 예제예요.
문제 세종대왕 단계 1 / 2 코드 0 / 6 자연어 지식을 읽고 알맞은 의미망 그림을 클릭하세요.

자연어 지식

    술어 읽는 방법 — is_a(~이다) · has(~을 가지고/거느리고 있다) · make(~을 만들었다) · cowork(~와 협력한다) · study(~을 공부한다) · write(~을 썼다) · draw(~을 그렸다) · teach(~을 가르쳤다)

    1단계 — 알맞은 의미망 고르기

    아래 세 그림 중 위의 지식을 올바르게 표현한 의미망은 하나뿐입니다. 화살표의 방향(주어 → 대상)과 술어(관계 이름)를 비교해 보세요.

    2단계 — 술어 논리 코드 고르기

    문장마다 올바른 술어 논리 코드를 클릭하세요. 술어와 인자(괄호 안)의 순서가 모두 맞아야 합니다.
