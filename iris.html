Data & Machine Learning — Iris Dataset

붓꽃 데이터로 배우는 기계학습

붓꽃(Iris) 데이터셋은 통계학자 피셔가 1936년에 붓꽃을 측정하여 만든, 기계학습에서 가장 널리 쓰이는 데이터셋입니다. 세 품종(세토사·버시컬러·버지니카)의 붓꽃에 대해 꽃받침과 꽃잎의 길이·너비를 기록했습니다.

이 사이트에서는 교과서 2단원의 기계학습 문제 해결 과정을 그대로 따라가며, "꽃잎과 꽃받침의 크기로 붓꽃의 품종을 분류하는 지능 시스템"을 직접 만들어 봅니다.

기계학습 문제 해결 과정

기계학습으로 문제를 해결하는 과정은 다음 순서로 진행됩니다. 위의 탭을 순서대로 따라가 보세요.

단계하는 일탭
① 데이터 수집문제 해결에 필요한 데이터를 모으고 통합합니다. (Iris1.csv 150개 + 새로 수집한 Iris2.csv 30개)데이터 살펴보기
② 데이터 전처리결측치·이상치를 처리하고, 핵심 속성(꽃잎 길이·너비)을 찾습니다.데이터 전처리
③ 모델 학습훈련 데이터로 k-최근접 이웃(k-NN) 분류 모델을 학습시키고 새로운 붓꽃을 분류합니다.k-NN 분류
④ 성능 평가테스트 데이터의 혼동행렬로 정확도·정밀도·재현율·F1-점수를 구합니다.성능 평가

데이터 살펴보기

Exploring the Iris Dataset

기계학습의 재료는 데이터입니다. 데이터는 속성명(꽃받침 길이, 종류 등)과 속성값(5.1, 세토사 등)으로 이루어지고, 속성은 유형에 따라 수치형·범주형으로, 역할에 따라 독립 변수·종속 변수로 구분합니다. 피셔의 원본 데이터 150개에 새로 수집한 30개를 통합한 180개의 데이터를 직접 살펴보고, 속성 구분 퀴즈를 풀어 보세요.

활동 안내

  • 표에서 180개의 붓꽃 데이터를 살펴보세요. 품종 버튼으로 골라 볼 수 있고, 151~180번은 새로 수집한 데이터(NEW)입니다.
  • 새로 수집한 데이터에는 값이 비어 있는 칸('–')이 보일 거예요. 이런 값을 어떻게 처리하는지는 데이터 전처리 탭에서 다룹니다.
  • 오른쪽 퀴즈 3문제로 수치형·범주형, 독립 변수·종속 변수를 구분해 보세요.

데이터 전처리

Data Preprocessing

수집한 데이터를 그대로 쓰면 기계학습이 제대로 되지 않습니다. 누락되어 비어 있는 결측치와, 범위를 크게 벗어난 이상치를 찾아 제거하고, 속성 간 상관관계를 분석해 문제 해결에 가장 큰 영향을 주는 핵심 속성을 찾아냅니다.

활동 안내

  • 1단계 — 새로 수집한 30개 데이터에서 결측치('–')가 있는 행을 모두 클릭해 선택한 뒤 제거하세요.
  • 2단계 — 남은 데이터의 기초 통계량(max)을 단서로, 이상치가 들어 있는 행을 찾아 제거하세요. 붓꽃의 크기는 보통 몇 cm 정도라는 점을 기억하세요.
  • 3단계 — 정제된 데이터의 상관계수 히트맵에서 상관계수가 가장 높은 속성 쌍을 골라 핵심 속성을 찾아내세요.

k-NN 분류

k-Nearest Neighbors Classification

k-최근접 이웃(k-NN)은 간단하고 직관적인 분류 알고리즘입니다. 새로운 데이터가 들어오면 기존 데이터 중에서 가장 가까운 k개의 이웃을 찾고, 다수결로 가장 많은 이웃의 품종을 새로운 데이터의 품종으로 결정합니다. 핵심 속성인 꽃잎 길이·너비의 산점도 위에 새로운 붓꽃을 직접 놓아 보며 체험해 보세요.

활동 안내

  • 산점도의 점 하나하나가 전처리를 마친 붓꽃 데이터입니다. 색이 품종을 나타내요.
  • 이웃의 수 k를 정하고(기본 5), 그래프를 클릭해 새로운 붓꽃(⊗)을 놓으세요. 가장 가까운 이웃 k개가 노란 테두리로 표시됩니다.
  • 이웃들의 색을 세어 다수결로 새로운 붓꽃의 품종을 판단해 클릭하세요. 맞히면 투표 결과가 공개됩니다.
  • 교과서 예제 버튼은 교과서 81쪽의 "꽃잎 길이 1.0, 꽃잎 너비 1.5" 붓꽃을 놓아 줍니다.
  • k를 바꾸면 분류 결과가 달라질 수 있어요. 품종의 경계 근처에 점을 놓고 k를 바꿔 보며 비교해 보세요.

성능 평가

Model Evaluation

학습을 마친 모델이 얼마나 잘 분류하는지는 학습에 쓰지 않은 테스트 데이터로 평가합니다. 예측 결과를 실젯값과 비교해 정리한 표가 혼동행렬(confusion matrix)이고, 이로부터 정확도 · 정밀도 · 재현율 · F1-점수 같은 평가 지표를 계산할 수 있습니다.

활동 안내

  • 1단계 — 테스트 데이터 30개의 3×3 혼동행렬을 읽고 정확도를 분수로 구하세요.
  • 2단계 — 교과서 81쪽 스스로 해결하기: "버시컬러인가?"를 기준으로 2×2 혼동행렬(TP·FN·FP·TN)을 만들어 보세요.
  • 3단계 — 2×2 혼동행렬로 정밀도·재현율·F1-점수를 계산하세요.
