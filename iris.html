1. 데이터 이해하기

Understanding the Iris Dataset

기계학습의 재료는 데이터입니다. 붓꽃(Iris) 데이터셋은 통계학자 피셔가 1936년에 만든, 기계학습에서 가장 널리 쓰이는 데이터셋으로, 세 품종(세토사·버시컬러·버지니카)의 꽃받침·꽃잎 길이와 너비를 기록했습니다. 먼저 데이터를 직접 살펴보며 속성의 유형과 역할을 구분하고, 새로 수집한 데이터에 섞인 결측치와 이상치를 청소한 뒤, 핵심 속성을 찾아냅니다.

🌼 특성(feature)과 정답(label)

아래는 붓꽃 데이터의 일부입니다. 꽃잎·꽃받침의 길이·너비처럼 모델이 보고 학습하는 값을 특성(feature), 우리가 맞히고 싶은 값(품종)을 정답(label)이라고 합니다.

🔵 특성 (feature) = 독립 변수 X 🟢 정답 (label) = 종속 변수 y
일련번호 꽃받침 길이 꽃받침 너비 꽃잎 길이 꽃잎 너비 종류
15.13.51.40.2세토사
24.93.01.40.2세토사
517.03.24.71.4버시컬러
1016.33.36.02.5버지니카

💡 표의 파란 배경 열이 특성(X), 초록 배경 열이 정답(y)입니다. 모델은 파란 열만 보고 초록 열을 맞히도록 학습해요. 특성은 결과에 영향을 주므로 독립 변수, 정답은 특성의 영향을 받으므로 종속 변수라고도 부릅니다. (일련번호는 데이터를 구분하는 번호일 뿐, 학습에 쓰지 않아요.)

활동 안내

  • 표에서 180개의 붓꽃 데이터를 살펴보세요. 151~180번은 새로 수집한 데이터(NEW)로, 값이 비어 있는 칸('–')이 섞여 있어요.
  • 속성 퀴즈 3문제로 수치형·범주형, 독립 변수·종속 변수를 구분해 보세요.
  • 아래 산점도에서 X·Y축 속성을 바꿔 가며, 어떤 속성 조합이 세 품종을 가장 잘 갈라놓는지 눈으로 확인해 보세요.

활동 안내

  • 1단계 — 새로 수집한 30개 데이터에서 결측치('–')가 있는 행을 모두 클릭해 선택한 뒤 제거하세요.
  • 2단계 — 남은 데이터의 기초 통계량(max)을 단서로, 이상치가 들어 있는 행을 찾아 제거하세요. 붓꽃의 크기는 보통 몇 cm 정도라는 점을 기억하세요.
  • 3단계 — 정제된 데이터의 상관계수 히트맵에서 상관계수가 가장 높은 속성 쌍을 골라 핵심 속성을 찾아내세요.

2. 분류 (k-NN)

Classification with k-Nearest Neighbors

k-최근접 이웃(k-NN)은 새로운 데이터가 들어오면 가장 가까운 k개의 이웃을 찾아 다수결로 품종을 결정하는, 간단하고 직관적인 지도학습(분류) 알고리즘입니다. 핵심 속성인 꽃잎 길이·너비의 산점도 위에 새로운 붓꽃을 직접 놓아 보고, 훈련 데이터와 테스트 데이터를 나누어 모델의 정확도까지 확인해 봅니다.

활동 안내

  • 산점도의 점 하나하나가 전처리를 마친 붓꽃 데이터입니다. 색이 품종을 나타내요.
  • 이웃의 수 k를 정하고(기본 5), 그래프를 클릭해 새로운 붓꽃(⊗)을 놓으세요. 가장 가까운 이웃 k개가 노란 테두리로 표시됩니다.
  • 이웃들의 색을 세어 다수결로 새로운 붓꽃의 품종을 판단해 클릭하세요. 맞히면 투표 결과가 공개됩니다.
  • 교과서 예제 버튼은 교과서 81쪽의 "꽃잎 길이 1.0, 꽃잎 너비 1.5" 붓꽃을 놓아 줍니다.
  • 품종의 경계 근처에 점을 놓고 k를 바꿔 보며 분류 결과가 달라지는지 관찰해 보세요.

활동 안내

  • 모델을 공정하게 평가하려면 데이터의 일부는 학습(훈련)에만, 나머지는 평가(테스트)에만 써야 합니다.
  • ① 8:2로 나누기를 눌러 훈련·테스트 데이터를 나누고, ② 학습하고 채점하기로 k-NN 모델의 테스트 결과를 확인하세요.
  • 나누기 버튼을 여러 번 눌러 보세요 — 누를 때마다 테스트 데이터(노란 점)의 위치가 무작위로 달라집니다. 코드에서 random_state를 지정하지 않으면 실행할 때마다 이렇게 다르게 나뉘어요.
  • 마지막으로 정확도를 분수로 직접 계산해 입력해 보세요. 분할이 달라지면 정확도도 조금씩 달라집니다.

3. 모델 평가

Model Evaluation

학습을 마친 모델의 성능은 학습에 쓰지 않은 테스트 데이터로 평가합니다. 예측 결과를 실젯값과 비교해 정리한 표가 혼동행렬(confusion matrix)이고, 이로부터 정확도 · 정밀도 · 재현율 · F1-점수를 계산합니다. 같은 정확도라도 문제에 따라 봐야 할 지표가 달라진다는 것까지, 질병 진단 AI 예제로 확인해 보세요.

활동 안내

  • 1단계 — 테스트 데이터 30개의 3×3 혼동행렬을 읽고 정확도를 분수로 구하세요.
  • 2단계 — 교과서 81쪽 스스로 해결하기: "버시컬러인가?"를 기준으로 2×2 혼동행렬(TP·FN·FP·TN)을 만들어 보세요.
  • 3단계 — 2×2 혼동행렬로 정밀도·재현율·F1-점수를 계산하세요.
  • 4단계 — 교과서 78~79쪽의 질병 진단 AI 혼동행렬로 같은 지표를 계산하고, "왜 정확도만으로는 부족할까요?"를 열어 이유를 확인하세요.
  • 더 알아보기 — k를 1~79까지 바꿔 가며 훈련·테스트 정확도 그래프로 과대적합과 과소적합을 관찰해 보세요.

4. 군집화 (k-means)

Clustering with k-Means

이번에는 정답(품종) 열이 없는 데이터입니다. k-평균(k-means) 군집화는 레이블 없이 비슷한 데이터끼리 스스로 묶는 비지도학습 알고리즘으로, 중심 배치 → 군집 할당 → 중심 이동을 중심이 멈출 때까지(수렴) 반복합니다. 단계별로 직접 실행해 보고, 다 묶인 뒤에 실제 품종과 비교해 보세요.

활동 안내

  • 군집 수 k(2~4)를 정하고 다음 단계 버튼으로 한 단계씩 실행하세요: 중심(◆) 배치 → 각 점을 가까운 중심에 할당 → 중심을 평균 위치로 이동.
  • 중심이 더 이상 움직이지 않으면 수렴입니다. 자동 반복으로 빠르게 돌릴 수도 있어요.
  • 수렴한 뒤 실제 품종과 비교해 보기를 켜서, 정답 없이도 품종과 비슷하게 묶였는지 확인하세요. k=2, 4일 때와도 비교해 보세요.
  • 군집 내 거리 합이 반복할수록 어떻게 변하는지도 관찰해 보세요.
